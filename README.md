## PACE Methodology

This project follows the structured **PACE** framework to ensure a rigorous and business-oriented data workflow:

1.  **Plan** — Defining project goals, gathering requirements, and understanding the business context.
2.  **Analyze** — Conducting Exploratory Data Analysis (EDA), discovering patterns, cleaning, and preparing data.
3.  **Construct** — Building models, calculating metrics, and developing technical solutions.
4.  **Execute** — Presenting results, drawing conclusions, and formulating actionable recommendations for stakeholders.
